An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with a written guide to each trophy and its sources, a roadmap to the platinum, missable warnings, filters, a spoiler setting and progress saved in the browser. Static files, no build step, no network at run time.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Hand it in as an entry:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
